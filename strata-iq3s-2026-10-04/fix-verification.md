# Strata + IQ3_S 循环恢复验证

修复配置已部署。原题 31 份全部自然完成：0 空正文，0 截断。第一轮 94.0/100，第二轮 96.8/100。独立评分的 40 项检查未出现重大违规封顶。

Strata 增加了可选的重复推理检测与恢复。检测器统计最近 2,000 个词中，出现至少三次的 12 词片段覆盖率；达到 25% 后，保留原题和全部已生成 token，将原生思考提示从 xhigh 改为 low，并从已有思考继续生成；旧采样参数在恢复时提高到至少 temperature=1.0、presence_penalty=1.5，并使用 top_p=0.95、top_k=20。本批 4 个请求触发恢复。它不设置独立思考预算，不插入结束思考标签，不追加纠错题面，也不重新挑选答卷。

模型权重、原始 tokenizer 和题目没有更换。数值路径使用 STRATA_IQ_MT_MIN=1，关闭 prompt cache、专家自适应交换和未命中专家的 PCIe 搬运；未命中的专家由 CPU 计算。采样为 temperature=1.0、top_p=0.95、top_k=20、presence_penalty=1.5。输出上限仍为 65,536 token，包含思考及正文。

原有服务测试 118 项、新增恢复测试 7 项全部通过。部署版对旧采样参数另有保护；本批原题已经使用恢复采样，新增分支不会改变这 31 份原题的采样参数对象，该行为有单测覆盖。重启发生在第四份答卷前；部署后又通过未显式提供采样、思考档位及输出上限的原题请求，验证默认配置生效。随后使用原 D8 失败思考中包含 2 次连续重复的真实前缀，在同一个已加载引擎、同一随机种子、相同 16K 输出上限下作对照：控制组连续重复 1,487 次，耗尽上限且没有最终正文；恢复组触发一次恢复，在 6,655 token 内自然完成并给出非空最终答卷。该回放单独保存，不替换任何榜单答卷。另一次使用严格数值路径的 32K 回放没有重现原字面重复，但控制组仍耗尽推理上限；恢复组在 10,568 token 内完整完成。原题 D2 也有同题、同种子、同采样、同 64K 上限的对照：失败与修复答卷共有 138,470 个完全相同的思考字符，控制答卷最终耗尽 65,536 token 而没有正文，修复答卷在 60,955 token 内完整结束。
