# 多模型能力测试题库

这套题用于比较大语言模型（Large Language Model，LLM）在真实代理工作中的能力结构与重复运行稳定性。它不测试生成速度，也不把价格计入能力分。

## 两轮分别测什么

### 第一轮：超长整包压力测试

[第一轮完整题目](./round1-long-package.md)把十类任务放入一个请求，观察模型在长答案中的注意力竞争、跨任务约束保持、输出预算分配和整包交付能力。

第一轮适合发现长任务失稳，但单次结果容易受随机性和输出预算影响。不要只凭一次运行建立稳定排行榜；复测时建议至少运行 3 次，并同时报告全部原始答案与分数范围。

### 第二轮：拆题后的能力与稳定性测试

[第二轮十项独立题目](./round2-independent-prompts.md)把十类任务拆为十个独立新会话，每项运行 3 次，共得到 30 份答案。它更接近多代理系统把不同任务分给独立工作代理的方式。

十个能力维度中，D 是 Dimension（能力维度）的缩写，D1–D10 的数字表示能力项目编号：

1. 逻辑与定量推理
2. 代码实现与并发
3. 调试与代码审查
4. 代理规划与工具使用判断
5. 长上下文综合与权威来源判断
6. 研究与证据判断
7. 中文约束沟通
8. 创意与产品设计
9. 规划与证据驱动决策
10. 指令忠实与事实边界

## 推荐运行协议

1. 每道题都在全新会话中运行，不携带其他题目、答案或模型信息。
2. 第二轮每题独立运行 3 次，推荐先完成 D1–D10 的第 1 次，再整体完成第 2、3 次。
3. 参测模型不得浏览网页、读取本地文件、执行代码、使用插件或委派子代理。
4. 不追加纠错提示，不要求模型改稿；保存第一次返回的完整最终正文。
5. 记录准确模型版本、调用渠道、推理档位、温度、随机种子、最大输出预算和结束原因；平台未公开的配置明确写“未知”或“平台默认”。
6. 空正文、截断、虚构工具执行和传输失败分别记录，不要静默删除异常样本。
7. 不比较速度。若不同模型使用不同输出预算或工具权限，必须显著披露。

对于带工具的代理产品，请在每道题前加入下面的闭卷说明：

```text
You are participating in a closed-book capability evaluation.

- Do not browse, use tools, inspect local files, execute code, or delegate to another agent.
- Answer this one task directly and return only the final answer.
- Preserve evidence boundaries, show calculations when requested, and never claim tool use or execution that did not occur.
- Follow all length, format, and content constraints exactly.
```

## 结果应该怎样报告

- 第一轮：每次整包总分、完整性、输出截断情况和多次运行范围。
- 第二轮：十项能力各自的三次中位数、最低到最高范围、无效回答率，以及三次整套得分。
- 排名之外必须同时公开原始答案、模型配置和异常样本。
- 0.2–0.4 分的小差距不应在只有三次样本时解释为显著领先。

## 当前公开范围

本目录只公开候选模型看到的题目与运行方法，不包含私有评分表、参考答案、匿名映射、模型密钥或内部判分记录。这样可以让其他人复测，同时避免直接把答案提示给参测模型。
